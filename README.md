# BIORYX — итоговая сборка

Для обновления существующего магазина откройте `ИНСТРУКЦИЯ.md`. В комплект входят витрина, единый Worker со встроенной панелью, миграции D1 до 0023 и тестовые товары и изображения. Старые промежуточные архивы устанавливать не нужно.

Не запускайте `worker/setup.sql` на работающей базе; не публикуйте секреты в GitHub. Реальное развёртывание и интеграции в вашей Cloudflare/Telegram-среде не проверялись. До продаж необходимы отдельное тестирование и проверка безопасности и юридических требований.
