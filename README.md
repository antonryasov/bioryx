# BIORYX — тестовый запуск на GitHub Pages и Cloudflare

Подробно: **[ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)**. В проекте нет отдельного сервера: API выполняется в Cloudflare Worker, база — D1, сайт размещается на GitHub Pages.

Содержимое: страницы сайта; `assets/config.js` — адрес Worker; `data/products.json` — локальная демонстрационная копия каталога; `worker/src/index.js` — Worker; `worker/setup.sql` — таблицы и тестовые товары; `worker/migrations/` — те же SQL-команды по частям; `docs/ANALYSIS.md` — анализ старой базы. Изображения товаров сгенерированы как иллюстрации, товары и цены вымышлены.

Рабочий контур после настройки: каталог и остатки из D1, корзина, оформление, серверная проверка цены и остатка, запись заказа и списание остатков, уведомление владельцу через Telegram, приветственный клиентский бот со ссылкой на каталог. При неудаче Telegram уведомление остаётся в очереди и может быть повторено по расписанию или вручную.

**Это тестовый контур, не готовый к реальным продажам.** Нет CRM, личного кабинета и полноценного клиентского бота, интеграции с API СДЭК, расчёта стоимости доставки, онлайн-подтверждения СБП, юридических документов, защиты от спама/лимитирования, управления возвратами и автоматического восстановления остатков при отмене. Доставка и оплата согласуются вручную. Нужны полноценное тестирование и проверка требований по обработке персональных данных перед коммерческим запуском. Секреты никогда не сохраняйте в репозиторий.
